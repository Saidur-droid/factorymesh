# FactoryMesh Investor Data Room Checklist

Use a restricted-access data room for sensitive documents. Do not commit confidential legal, identity, customer, factory, banking or investor documents to the public repository.

## 00 — Index
- data-room index
- latest investor deck
- investor one-pager
- current fundraising status
- contact owner

## 01 — Corporate
- certificate of incorporation
- memorandum/articles or constitutional documents
- trade licence if applicable
- TIN/tax registration
- VAT/BIN if applicable
- registered office
- board/shareholder resolutions
- statutory registers

## 02 — Cap table & financing
- fully diluted cap table
- founder shares
- options/ESOP if any
- prior SAFEs/convertibles/equity
- shareholder agreements
- prior investment documents
- any debt/liens/guarantees

## 03 — Founder & team
- founder bio/CV
- employment/consulting agreements
- founder vesting if applicable
- IP assignment
- confidentiality agreements
- key-hire plan

## 04 — Product & technology
- architecture
- security model
- production status
- test/CI evidence
- deployment diagram
- incident/recovery plan
- dependency/licence review
- data-flow map
- privacy/security controls
- AI/model usage boundaries
- product roadmap

## 05 — Commercial
- buyer pipeline
- signed LOIs/pilot agreements
- order briefs
- reservations
- invoices
- collected payments
- buyer references with consent
- factory onboarding/participation agreements
- commercial pricing policy
- sales funnel

## 06 — Traction metrics
- verified factories
- verified capacity
- buyer briefs
- reservations
- fulfilled/shipped GMV
- revenue
- take rate
- repeat buyer rate
- time to credible match
- capacity accuracy
- on-time production/shipment
- dispute/cancellation rate

## Diligence rule

Every claimed metric must have a source object.

Examples:
- “3 reservations” → three reservation records/contracts
- “$500k GMV” → underlying order records
- “$10k revenue” → invoices + receipt/bank proof
- “80% capacity accuracy” → documented denominator/methodology
- “repeat buyer” → second real order/brief, not a verbal hope

Institutional capital rewards clean evidence.
