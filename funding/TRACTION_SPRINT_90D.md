# FactoryMesh — 90-Day ONKUR Traction Sprint

**Start:** 2026-09-20  
**Purpose:** turn the current working MVP into institutional-grade commercial evidence.

## Non-negotiable outcome

By the end of this sprint, FactoryMesh should aim to have:

- production-live infrastructure
- 10+ verified factories
- 3+ genuine buyer briefs
- 3+ real capacity reservations
- 1+ shipped order
- first collected FactoryMesh fee
- at least one repeat-buyer signal
- initial capacity accuracy data
- first per-order contribution-margin record
- investor/data room ready
- lead-investor outreach active

These are targets, not claims.

## Days 1–14 — Production + company readiness

### Product
- create dedicated production Supabase project
- apply migrations
- verify RLS and storage
- deploy production Vercel app
- real buyer/factory accounts
- live buyer → factory → reservation → production → QC → shipment smoke
- test cross-tenant isolation
- test concurrent reservation safety
- monitoring/backups/recovery baseline

### Company
Confirm or complete:
- legal entity
- founder/shareholding structure
- cap table
- IP assignment
- bank/accounting setup
- commercial terms
- privacy/terms
- invoice template
- orchestration fee agreement
- factory participation/verification agreement

## Days 8–30 — Supply density

Focus only on the first category cluster.

Target:
**10–15 export-ready factories**

Collect:
- legal identity
- location
- product specialization
- machines/lines
- MOQ
- indicative lead time
- compliance/certification evidence
- 12-week capacity
- commercial/production contacts

Verification:
- weekly capacity refresh
- daily confirmation for active matched slots
- log every correction
- begin capacity-accuracy history

Do not optimize for factory-profile count.

Optimize for **credible bookable capacity**.

## Days 15–45 — Buyer acquisition

Target buyers:
- overseas emerging/mid-market apparel brands
- Bangladesh-entry brands
- sourcing offices
- buying houses needing overflow capacity
- seasonal/urgent capacity buyers

Founder pitch:

> **Send us one real production brief. We will return a verified, bookable capacity plan — not a factory list.**

Target:
- 30–50 high-quality buyer conversations
- 5 serious opportunities
- 3 genuine briefs

## Days 25–60 — Transactions

For every real brief:
1. normalize requirements
2. match hard constraints
3. verify live capacity
4. produce 1–3 options
5. explain route/risk
6. quote
7. reserve capacity
8. monitor production

Target:
**3 real reservations**

Measure:
- hours from brief to credible option
- number of external factory contacts required
- capacity accuracy
- quote turnaround
- buyer objections
- operator hours

## Days 45–90 — Shipment + revenue proof

Target:
- at least 1 successful shipment
- issue FactoryMesh invoice
- collect first orchestration fee
- record GMV
- record actual take rate
- record cost-to-serve
- record gross/contribution margin
- request repeat order / next brief
- create case study only with permission

## Investor work in parallel

### Week 2
- one-pager final
- deck source final
- data-room index
- incorporation/cap-table package

### Weeks 3–5
- build target institutional lead list
- seek warm introductions
- begin investor conversations as “traction sprint / upcoming Seed”

### Weeks 6–10
- share live metrics only
- move qualified investors into diligence
- ask for explicit next step

### Weeks 8–12
If commercial gate is met:
- submit/refresh ONKUR application
- pursue co-investment structure
- share data room under appropriate access control

## Kill / redesign triggers

Do not scale fundraising claims if:
- factories will not provide usable capacity
- capacity accuracy remains too low
- buyers do not value reservation/routing
- 2.5% creates consistent price rejection without equivalent value
- manual operator cost consumes the fee
- buyers bypass FactoryMesh immediately and no ongoing value remains

Institutional investors will discover these issues in diligence. Better to discover them first.
