## One-line description

**FactoryMesh turns Bangladesh RMG production capacity into verified, bookable and routable infrastructure for global brands.**

## Problem

Global apparel buyers can discover factories, but they still struggle to know which factory is actually available for an exact order, how much usable capacity exists, whether the cost/deadline/compliance requirements can be met and how to manage execution risk.

The current workflow is fragmented across relationships, emails, calls, spreadsheets, RFQs and manual capacity confirmation.

## Solution

A buyer submits an order brief or tech pack.

FactoryMesh:
1. normalizes requirements
2. verifies available capacity
3. ranks feasible factories
4. explains cost/lead-time/quality/compliance risk
5. recommends one-factory or split routing
6. enables capacity reservation
7. tracks production, QC and shipment
8. records actual outcomes to improve future routing

## Core product differentiation

1. Live 12-week Capacity Map
2. Capacity Confidence Score
3. Order Routing Engine
4. Capacity Reservation
