# FactoryMesh Metrics

## North-star metric
**Fulfilled manufacturing GMV routed through FactoryMesh.**

GMV alone is not enough; it must be paired with buyer value, trust, outcome quality and margin metrics.

## Core marketplace/orchestration metrics
- order briefs submitted,
- qualified order briefs,
- time to first credible match,
- time to confirmed/bookable capacity,
- match-to-quote conversion,
- quote-to-reservation conversion,
- reservation-to-production conversion,
- production-to-shipment completion,
- repeat buyer rate,
- active factories,
- verified capacity available,
- capacity utilization influenced by FactoryMesh.

## Buyer-value metrics

The commercial fee is only defensible if these improve:

- median time from brief to credible production plan,
- number of factories buyer had to contact outside FactoryMesh,
- percentage of briefs resolved with 1–3 executable options,
- percentage of recommended routes accepted,
- percentage of accepted routes successfully reserved,
- sourcing time/workload displaced where measurable,
- percentage of orders requiring backup routing,
- buyer-reported reduction in sourcing uncertainty,
- buyer repeat intent and actual repeat orders.

## Trust metrics
- declared capacity accuracy,
- capacity freshness,
- capacity-confidence calibration,
- reservation accuracy,
- on-time production start,
- on-time delivery rate,
- defect / rework rate,
- quote-to-realized-cost variance,
- cancellation rate,
- dispute rate.

## Unit economics
- take rate,
- revenue per order,
- gross margin per order,
- operator hours per order,
- operator cost per $100k GMV,
- verification cost per order,
- buyer acquisition cost,
- buyer gross-profit payback,
- contribution margin,
- net revenue retention when subscriptions launch.

## Pricing-validation cohort

The first five paid shipped orders use the locked launch pricing policy.

Track for each:
- order GMV,
- invoiced FactoryMesh fee,
- actual collected revenue,
- buyer price objection,
- discounts/waivers and reason,
- cost-to-serve,
- operator hours,
- gross margin,
- repeat order within the next buying cycle.

Do not call 2.5% “market validated” until real buyers pay it with acceptable economics.

## Product quality metrics
- percentage of recommendations accepted without operator override,
- percentage of capacity records refreshed on time,
- average age of capacity data,
- routing override reasons,
- time from brief to confirmed capacity,
- capacity reservation success rate,
- percentage of completed orders that update outcome history.

## Pilot targets (working targets, not promises)
- credible production option within 48 hours,
- 70%+ initial capacity accuracy, improving rapidly,
- at least 3 real reservations,
- at least 1 shipment,
- 50%+ repeat intent from successful pilot buyers,
- positive contribution margin path visible before scaling operations,
- operator effort per matched order falling quarter over quarter.

## Commercial milestone example

A useful early operating target is:

> **10 repeat buyers × $100k fulfilled GMV/month × 2.5% = $25,000 monthly revenue**

This is a scenario for planning, not a forecast or guarantee.

## Anti-vanity metrics
Do not optimize for:
- number of factory profiles,
- app signups,
- document uploads,
- AI-generated recommendations,
- countries shown on a map.

These matter only if they improve fulfilled GMV, routing quality, reservation conversion, buyer retention or economics.
