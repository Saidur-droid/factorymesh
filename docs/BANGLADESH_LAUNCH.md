# Bangladesh Launch Plan

## Pilot objective
Prove that FactoryMesh can reliably convert buyer demand into confirmed, executable Bangladesh production capacity faster than manual sourcing.

## Start narrow
Do not start with all RMG categories.

Recommended first wedge:
- knit tops / hoodies / t-shirts,
- factories with export history,
- 5–10 factories,
- 2–3 recurring buyers or sourcing partners.

## Factory onboarding
Collect only what is necessary:
- legal/company identity,
- factory location,
- product specialization,
- key machines/lines,
- typical MOQ,
- indicative lead times,
- current 12-week capacity,
- compliance/certification metadata,
- main commercial/production contacts.

Do not demand ERP integration at first.

## Capacity refresh cadence
- weekly mandatory refresh,
- daily confirmation for active matched slots,
- stale capacity confidence automatically decays,
- operator calls/WhatsApp may be used during pilot but every verification must be logged.

## Buyer onboarding
Initial buyer types:
- mid-market overseas brands,
- sourcing offices,
- buying houses needing overflow/backup capacity,
- brands seeking Bangladesh entry without building a full local sourcing team.

## Pilot offer
Buyer submits one real production brief.

FactoryMesh returns:
1. feasibility response,
2. 1–3 recommended production options,
3. capacity window,
4. indicative quote,
5. routing rationale,
6. reservation path.

## Commercial structure
Early pilots can use a simple success fee / orchestration fee tied to fulfilled GMV.

Avoid charging factories heavily before buyer demand exists.

## Local operating reality
Bangladesh execution will require relationship-heavy operations early on. That is acceptable if the software captures the operating data and progressively automates repetitive work.

## Pilot success criteria
- buyer receives credible shortlist/plan within 48 hours,
- at least 70% of declared capacity used in matching is accurate,
- at least 3 real production reservations,
- at least 1 order reaches shipment,
- buyer says FactoryMesh materially reduced sourcing time/uncertainty,
- at least 50% of pilot buyers request another order,
- factory updates can be maintained without high manual burden.

## Pilot kill / redesign signals
- factories refuse to share usable capacity data,
- capacity data changes too quickly to stay trustworthy,
- buyers still insist on direct manual sourcing with no value from orchestration,
- take rate is not enough to support operations,
- orders require so much custom human work that software leverage is weak.

## Expansion inside Bangladesh
Only after the first loop works:
- add more knit categories,
- add woven/denim,
- increase factory density by cluster,
- add QC workflow,
- add logistics integrations,
- add buyer forecasting and forward capacity reservations.
