# Competitive Intelligence — October 2026

**Purpose:** current competitive reality for FactoryMesh.  
**Last verified:** 3 October 2026.

This document is not a claim that competitors lack features we have not independently verified. It records what their current public materials show and defines the proof FactoryMesh must produce to justify its differentiation.

## FactoryMesh differentiation must be proven, not asserted

The defensible product thesis is the combination of:

1. **Live time-bound capacity** — capacity attached to a specific production window, not only factory capability or monthly aggregate.
2. **Capacity Confidence** — freshness and historical declaration accuracy change how much the system trusts a slot.
3. **Executable routing** — hard constraints plus explainable one-factory or split-order routing.
4. **Reservation** — the recommendation can become a real, auditable production-slot commitment.
5. **Outcome feedback** — actual start, quality, cost, shipment and cancellation outcomes change future recommendations.

Canonical loop:

**Factory -> Capability -> Capacity Window -> Buyer -> Quote -> Reservation -> Production -> QC -> Shipment -> Actual Outcome**

## The competition test

FactoryMesh loses its differentiation if a buyer experiences it as:

> upload brief -> browse factories -> request quotes -> manually choose one

FactoryMesh must instead progress toward:

> upload brief -> receive 1-3 capacity-backed executable routes -> understand risk -> reserve a specific slot -> monitor execution -> feed the actual outcome back into future routing

## Public-feature caution

As of this review, public competitor materials clearly show substantial supplier discovery, RFQ, matching, order and production workflow capabilities.

We have **not** established from public materials that no competitor supports time-bound capacity reservation or similar internal functionality. Therefore never pitch:

> "Nobody else does this."

Pitch:

> "Our product is deliberately optimized around verified time-bound capacity, reservation and execution outcomes, and we will prove whether that creates a better buyer result."

## Buyer-level differentiation tests

For each real buyer brief, measure:

- time to first credible capacity-backed option;
- number of manual supplier contacts required;
- percentage of proposed capacity still available when confirmed;
- route acceptance rate;
- reservation success rate;
- promised vs actual production start;
- promised vs actual delivery;
- quote vs realized cost;
- defect/rework outcome;
- repeat buyer behavior.

## Kill / redesign conditions

Reconsider the wedge if:
- factories will not provide sufficiently fresh capacity;
- public/competitive alternatives match the same job with better trust and network density;
- buyers do not value slot reservation/routing enough to pay;
- buyer/factory bypass removes most ongoing value;
- operator work does not fall with repeated use;
- outcome history does not improve routing quality.

The goal is not to sound unique. The goal is to become measurably better at one high-value manufacturing decision.
