## Current validation milestone

Prove the real loop:

**buyer brief -> verified time-bound capacity -> recommended route -> reservation -> production/QC -> shipment -> paid FactoryMesh fee -> repeat buyer signal**

## Evidence rule

Do not claim:
- live production readiness,
- real factory capacity,
- customer traction,
- shipped GMV,
- revenue,
- capacity accuracy,
- repeat buyers,
- partnerships,
- investor interest,

without a current source artifact that can be inspected.

Use **NEEDED**, **UNVERIFIED**, or **TARGET** when proof does not yet exist.

## Product rule

Do not drift into a generic supplier directory, RFQ marketplace, ERP, or sourcing agency.

The company is only differentiated if it becomes materially better at answering:

> Where can this exact order be produced, in this exact time window, at acceptable cost and execution risk, and can that capacity be reserved now?
