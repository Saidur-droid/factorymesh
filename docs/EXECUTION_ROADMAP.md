# Execution Roadmap

## Phase 0 — Validation
Objective: prove access to both sides before heavy engineering.

Deliverables:
- 20 buyer interviews,
- 20 factory interviews,
- 5–10 pilot factories willing to share capacity,
- 2–3 buyers willing to submit real briefs,
- standardized first-category capability taxonomy,
- sample capacity spreadsheet/template.

Exit condition:
At least one real order can be matched manually with data we can realistically collect.

## Phase 1 — Concierge MVP
Objective: run the loop with software-assisted human operations.

Build:
- buyer order intake,
- factory registry,
- 12-week capacity calendar,
- operator console,
- deterministic match scoring,
- quote/reservation workflow,
- audit log.

Exit condition:
3+ real reservations and at least 1 shipment.

## Phase 2 — Repeatability
Objective: reduce operator work and improve data freshness.

Build:
- capacity reminders/refresh workflow,
- structured capability evidence,
- production milestones,
- match explanation,
- outcome tracking,
- buyer repeat-order cloning,
- basic analytics.

Exit condition:
repeat buyers + improving contribution margin.

## Phase 3 — Network Density
Objective: become meaningfully better than manual sourcing in chosen categories.

Build:
- category-specific routing weights,
- capacity confidence engine,
- factory reliability score,
- automated document extraction,
- forward capacity reservation,
- QC workflow.

Exit condition:
network density materially improves buyer conversion and routing speed.

## Phase 4 — Multi-country
Objective: route demand across at least two countries.

Build:
- country-aware landed-cost model,
- tariff/logistics inputs,
- multi-country capacity comparison,
- split-order optimization,
- country operator tools.

Exit condition:
real order successfully routed across expanded network.

## Phase 5 — Manufacturing Control Plane
Objective: enterprise planning and API infrastructure.

Build:
- demand forecasting ingestion,
- scenario planning,
- policy-based routing,
- enterprise API,
- integrations with sourcing/ERP systems,
- partner ecosystem for QC/logistics/finance.

## Build order rule
Do not build Phase N+1 features to impress investors while Phase N economics are unproven.
